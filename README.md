# أداة إنشاء القوالب — منصة معين التعليمية

نسخة ويب ثابتة (Static) من أداة **قالب التجميعات / تحضيري**، تعمل بالكامل داخل المتصفح
دون أي خادم — مناسبة للنشر المباشر على **GitHub Pages** (أو أي استضافة ثابتة أخرى).

## ما الذي تفعله الأداة؟

- ارفع صور التمارين والواجبات (أو اسحبها أو الصقها بـ Ctrl+V) وأضف النصوص.
- يُوزَّع المحتوى **تلقائياً** على صفحات A4 بهوية المنصة: الهيدر + شريط الروابط + الخلفية + الفوتر.
- أزرار (انضمام · متابعة · تواصل معنا · هنا) روابط **تفاعلية** قابلة للنقر.
- التصدير: **PDF** (بجودة 300DPI وروابط قابلة للنقر) · **Word** · **صور PNG**.
- المحتوى يُحفظ تلقائياً في متصفحك (localStorage) ولا يُرسل إلى أي مكان.

---

## النشر على GitHub Pages — خطوة بخطوة

### 1) إنشاء مستودع جديد

1. افتح [github.com/new](https://github.com/new) بعد تسجيل الدخول.
2. اختر اسماً للمستودع (مثال: `template-tool`).
3. اجعل المستودع **Public** (مطلوب لتفعيل GitHub Pages مجاناً).
4. اضغط **Create repository**.

### 2) رفع ملفات الأداة (بدون أي برامج — من المتصفح فقط)

1. في صفحة المستودع الجديد اضغط على **uploading an existing file** (أو من قائمة **Add file ▾ → Upload files**).
2. افتح مجلد `template-studio-github-pages` في جهازك، وحدد **كل ما بداخله**
   (سترفع `index.html` ومجلدات `js` و`css` و`fonts` و`template` وملفات `README.md` و`.nojekyll`).
   > ⚠️ ارفع **محتويات** المجلد مباشرة حتى يكون `index.html` في جذر المستودع، وليس المجلد نفسه.
3. اسحب الملفات إلى منطقة الرفع ثم اضغط **Commit changes**.

> ملاحظة: ملف `.nojekyll` مخفي وقد لا يظهر في بعض أنظمة التشغيل — تأكد من رفعه (هو موجود داخل الحزمة، ووظيفته تعطيل معالجة Jekyll على GitHub Pages).
> إن صعُب رفعه، لا مشكلة: ملفات هذه الحزمة لا تبدأ بشرطة سفلية، لكن رفعه يبقى أضمن.

### 3) تفعيل صفحات GitHub

1. من صفحة المستودع: **Settings → Pages** (الإعدادات ← Pages).
2. في قسم **Build and deployment**:
   - **Source**: اختر `Deploy from a branch`.
   - **Branch**: اختر `main` (أو `master`) والمجلد `/ (root)`.
3. اضغط **Save** وانتظر دقيقة حتى يجهز الرابط.

### 4) فتح الأداة

ستجد الرابط أعلى نفس الصفحة بالشكل:

```
https://اسم-حسابك.github.io/اسم-المستودع/
```

افتحه من أي جهاز — ويمكنك مشاركته مباشرة مع فريقك.

## تحديث الأداة لاحقاً

عدّل الملفات المطلوبة ثم أعد رفعها بنفس الطريقة
(**Add file → Upload files** → Commit changes). سيظهر التحديث خلال دقيقة.

## بنية الملفات

| المسار | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية (البطاقتان) + المحرر |
| `css/style.css` | التنسيقات الكاملة (عربي RTL) |
| `js/` | منطق التطبيق + مكتبات التصدير (مدمجة محلياً) |
| `fonts/` | خط Cairo مستضاف محلياً (4 أوزان) |
| `template/` | صور القالب: الهيدر، شريط الروابط، الخلفية، الفوتر |
| `.nojekyll` | تعطيل Jekyll على GitHub Pages |

## تغيير صور القالب أو الروابط

- **الصور**: استبدل الملفات داخل مجلد `template` بنفس الأسماء
  (`header.jpg` · `links-bar.png` · `page-bg.jpg` · `footer.png`).
- **الروابط**: عدّل الثوابت `LINKS` والنسب في ملف `js/template.js`
  (`LINKS_BAR_HOTSPOTS` لمواضع أزرار شريط الروابط، و`FOOTER_HOTSPOTS` للفوتر).

## ملاحظات تقنية

- كل شيء يعمل داخل المتصفح: لا خادم، لا قاعدة بيانات، لا إرسال بيانات.
- ملفات PDF/Word/الصور تُنشأ محلياً في جهاز المستخدم مباشرة.
- الحزمة لا تحتاج أي خطوة بناء (Build) — ارفعها كما هي.
- تعمل أيضاً محلياً بفتح `index.html` مباشرة، لكن التصدير والخطوط
  يعملان بأفضل شكل عند الاستضافة (GitHub Pages) لأن المتصفح يقيّد
  بعض العمليات على الملفات المحلية (file://).
